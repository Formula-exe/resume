# Signature font

`signature-zh.woff2` is a three-character subset (`张名宇`) of Ma Shan Zheng,
used only to sample the decorative Canvas signature. The font is served locally;
no third-party font service is required at runtime.

Source: https://github.com/google/fonts/tree/main/ofl/mashanzheng
