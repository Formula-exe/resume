# 单音轨播放控制检查

已在 [网站](http://127.0.0.1:8765/) 右上角加入声音按钮。首次进入为暂停状态，点击后才准备连接并播放。音源、音量、循环和加载超时集中在 [audio-config.js](../../audio-config.js)。本轮使用本地轻柔测试音，默认音量 0.18，加载超时 15 秒。

## 实现行为

- 页面仅有一个 `#siteAudio` 元素；暂停后继续播放保留当前进度，不因点击重新创建音频。
- 第一次播放才建立一个 AudioContext、一个 MediaElementAudioSourceNode、一个 GainNode，路由为 `source → gain → destination`。后续点击、失败重试及页面恢复复用这些对象和连接。
- 按钮的“播放中”状态取决于 `playing` 事件、实际 `paused / ended / error` 属性、`play()` 结果及输出连接状态；点击播放时先显示准备状态，不能先宣称播放成功。
- 加载或缓冲中按钮仍可操作，再次点击可以取消。请求按版本区分，较早请求的成功或失败不会覆盖后一次点击。
- 媒体加载错误、浏览器拒绝播放、解码/格式问题与超时都显示提示，可点击重试。声音输出恢复超时后也能用同一连接重试。
- `aria-pressed` 表示实际播放状态，`aria-busy` 表示准备状态；可用空格或 Enter 操作，中英文标签跟随网站语言。
- 音频代码不调用章节更新、星点重绘或人物更新，也没有新增声音分析与视觉响应。

`play()` 的成功或拒绝处理依据 [MDN HTMLMediaElement.play 文档](https://developer.mozilla.org/en-US/docs/Web/API/HTMLMediaElement/play)。实现文件为 [audio-control.js](../../audio-control.js)。

## 浏览器验证结果

| 检查 | 结果 |
| --- | --- |
| 实际播放与暂停 | 播放时媒体时钟前进且 AudioContext 为 running；暂停后时钟停止。 |
| 实际声音输出 | 验证脚本临时接入测量节点，取得非零 RMS；测量节点只存在于测试，随后断开。 |
| 连续播放/暂停 | 6 个完整循环通过，保留同一个音频元素和连接对象。 |
| 快速连点 | 30 次和 31 次两组，共 61 次，最终分别为暂停和播放，无第二条音轨。 |
| 初始化与连接计数 | 1 个 AudioContext、1 个媒体源、1 个 Gain；核心路由只 connect 两次，未使用 new Audio()。 |
| 外部暂停与键盘 | 媒体元素直接暂停后按钮同步；空格、Enter 正常切换。 |
| 播放被拒绝 | 注入 NotAllowedError 验证拒绝分支，提示显示、播放状态为 false；恢复真实方法后重试成功。 |
| 加载失败 | 请求返回实际 404 后显示错误；恢复文件后通过同一媒体元素重试成功。 |
| 取消加载 | 故意延迟真实请求，取消后晚到的资源不会自动开始播放，再次点击可播放。 |
| 加载超时 | 将测试超时临时设为 200 ms，保持请求挂起；显示超时提示，恢复后重试成功。正式参数仍为 15 秒。 |
| 输出连接超时 | 模拟输出恢复未完成，超时后再用真实 resume 恢复；AudioContext 与媒体源保持同一对象。 |
| 播放结束 | 测试时关闭循环并加快播放，实际到达结尾后按钮回到暂停。正式配置仍为循环播放。 |
| 星空保持原样 | 签名、人物、背景星点画布导出数据在操作前后完全相同；当前章节参数完全相同。 |
| 布局与语言 | 390 / 320 / 900 px 无横向溢出，按钮可点击，中英文标签正常。 |
| 浏览器脚本错误 | 0。故意制造的加载失败是已处理的验证场景。 |
