# Moonlight 三层音乐响应

[打开真实音乐演示](http://127.0.0.1:8765/output/music-response-review/) · [打开完整网站](http://127.0.0.1:8765/#top)

现有网站已接入参考图的三层响应。演示页只嵌入一个网站实例，所有演示按钮复用该实例的同一个音频元素。点击播放开始，不自动播放。

## 三层实现

| 层次 | 实际输入 | 页面表现 |
| --- | --- | --- |
| 实时频段 | 原 AnalyserNode 的频域数据，40–250 / 250–2000 / 2000–12000 Hz | 播放按钮的三条柱，按真实数据独立变化 |
| 音频预分析 | 当前 MP3 的能量、频谱变化起音、频谱重心音区估计 | 能量参与近层亮度；起音短暂提亮单个现有星点；音区决定人物轮廓提亮带的高度 |
| 手工时间编排 | 当前曲目专属的段落及 6 个流星时间窗 | 蓄势、展开、回旋、星潮、静息与尾声强弱变化；少量流星只在首屏右侧出现 |

音区按频谱重心估计，不是旋律转录或精确音高。起音也不是节拍识别。流星为手工编排，不声称由实时拍点自动产生。

预分析和编排直接按音频的 `currentTime` 读取。暂停时不再推进时间；向前或向后定位会取新位置的数据，不补放错过的流星。视觉参数由 `audio-star-response.js` 的同一个更新流程限幅、平滑；单帧间隔最多 0.05 秒。

## 保持阅读与原有构图

- 原有正文、简介、链接及项目内容保持相同，HTML 的选中、点击和键盘操作继续可用。
- 固定相机、签名、人物位置与粒子数量保持相同。人物仍为 36000 个粒子；从原几何选择 12020 个轮廓候选，不增加粒子，只在着色器中调整选中高度附近的亮度。
- 原有近层星点组的整体亮度参数限制为 1.45 倍。单颗起音短闪另以低透明度叠加在现有星点的位置，不额外随机撒点。
- 阅读作品时视觉系数 0.12，关于 0.25，其他正文为 0.08–0.18；原章节背景衰减继续生效。流星在这些阅读章节关闭，左侧文字区保持清楚。
- 人物动态绘制上限 18 FPS，隐藏的人物不持续绘制；流星层没有独立循环，没有活跃时间窗时也不持续重绘空画布。
- 暂停、缓冲或播放失败时所有音乐驱动强度平滑回落，回落后停止视觉循环。
- 系统减少动效或网站暂停动效时，场景恢复静态；音乐按钮显示固定三柱作为播放状态，RMS 仍可读取，主动播放音乐保持可用。

## 当前曲目与换曲

当前音频为 Scott Buckley《Moonlight》，音量保持 0.14；许可与原文件见 `assets/audio/README.md`。

- 时长：254.3337 秒。
- SHA-256：`7feb8c703983dbdfc97018f004cfebad8f03b86f2382c58c0ad24e375d4c17f5`。
- 5473 帧特征，349 个近似起音点，6 个手工流星时间窗。
- 运行时先核对实际音频文件的 SHA-256，匹配后使用当前预分析数据与编排。
- 文件变化后清除旧特征和旧编排。新音频在原 AudioContext 中解码，在 Worker 中重新分析；不创建第二条音轨。
- 未单独校准的新曲显示“新曲已分析 · 编排待校准”，只启用该曲的新分析和实时响应，关闭旧段落与流星。新曲手工编排完成后，需要更新配置中的文件校验、时长、段落和流星时间点。
- 预分析暂时失败时，保留实际音乐与实时频段/RMS；再次播放可重试准备视觉。

## 集中调整

| 文件 | 参数 |
| --- | --- |
| `audio-config.js` | 音频路径、音量、循环、超时、FFT 大小 |
| `audio-stars-config.js` | 基础亮度、RMS 增益、上下限、平滑速度、暂停回落、章节衰减 |
| `music-response-config.js` | 三频段范围、能量/起音/编排权重、人物提亮带宽与增益、绘制频率、曲目校验与时长、手工段落、流星时间/路径/透明度 |
| `assets/audio/moonlight-analysis.json` | 当前曲目的预分析结果 |

`build-analysis.py` 使用与网站相同的音频解码器及 Worker 生成当前曲目的预分析文件。`dev-server.py` 支持音频 HTTP Range，可在本地正常定位音乐。

## 实测

检查脚本为 `verify-music-response.py`，完整记录在 `verification.json`。

- 首屏开/关两次记录的音乐时间均为 **105.800091 秒**；关于章节均为 **70.400317 秒**。截图中的标题、简介和正文区域逐像素一致。
- 实际播放中低频范围约 0.599–0.749，中频 0.624–0.730，高频 0.265–0.311；三柱都实际变化。
- 关于章节的两个片段，人物提亮高度分别约 0.676 和 0.290，代表从肩颈附近移至头脸附近；人物相机、位置、大小及高光几何指纹保持相同。
- 检查 30、120、165、245、45.8、5 秒的前后定位，预分析读取时间与实际媒体时间相差小于 0.04 秒，没有补放过期流星。
- 作品章节亮度约 1.051 倍，流星关闭；Enter 选项目、方向键连续切换、Esc 关闭均正常。
- 暂停后亮度从 1.4124 倍柔和回落到 1.2263 倍，再回到 1 倍；人物提亮、起音和编排强度归零，视觉循环停止。
- 减少动效下，视觉与三频柱保持静态，音乐时间继续前进；暂停后主动重新播放正常。
- 换成另一个真实 WAV 文件后，自动重新分析，状态为 `ready-uncalibrated`；旧段落和 6 个流星时间点全部停用。切回当前 MP3 后重新验证并恢复专属编排。
- 包含换曲、暂停恢复和 20 次连续点击后，仍为 **1 个音频元素、1 个 AudioContext、1 个媒体源、1 个 GainNode、1 个 AnalyserNode、3 条原有连接**；波形和频域数组各分配一次。
- 签名、静态远/中层、近层缓存与星点几何保持相同。390 × 844 手机视口无横向溢出。主流程浏览器异常与资源失败均为 0。

额外检查见 `verify-music-review.py` 与 `additional-verification.json`：预分析请求失败时声音继续、保留实时响应，重新播放后准备成功；主动播放被拒绝时显示失败并平滑回落，重试恢复。交付页的外部按钮确实控制嵌入网站的同一条音轨，可点播星潮段和人物段、开关视觉、查看原尺寸对照；减少动效下播放按钮保持可用，手机视口无横向溢出。
