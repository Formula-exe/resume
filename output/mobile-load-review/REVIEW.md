# 手机构图与低负载检查

本轮修改的是现有网站的适配与渲染管理。真实标题、简介、项目资料、电话、邮箱与音乐保留。

## 使用方式

- 手机：导航菜单 → 画面设置。桌面：顶部齿轮；页尾也有入口。
- 自动：760px 以下，以及 1024px 以下的触控横屏设备使用低负载；开启节省流量时也选低负载。
- 标准：完整粒子；Bloom 默认关闭，可以手动开启。
- 低负载：降低像素比、粒子预算、绘制与采样频率，关闭 Bloom 和抗锯齿。
- 静态：释放动态视觉资源，使用静态签名、人物和星空；项目星图使用 SVG。
- 系统“减少动态效果”优先使用静态背景，仍可主动播放 / 暂停音乐。取消减少动效后恢复之前选择的模式。
- WebGL 创建失败或上下文丢失时切换静态背景，可在画面设置中重试。

## 修改与解决的问题

| 修改 | 解决的画面或运行问题 |
| --- | --- |
| 手机正文在上、签名与侧影在下 | 避免把桌面左右构图压缩到狭窄屏幕；主角不遮正文、按钮和链接 |
| 菜单使用独立浮层，设置关闭后焦点回到菜单按钮 | 菜单不再推移整个页面或使章节位置缓存失准；键盘焦点有明确落点 |
| 音乐视觉开关在手机移到页尾 | 小屏幕固定悬浮条不再覆盖电话与复制邮箱按钮；音乐播放按钮保留在顶部 |
| 渲染预算集中在 `visual-runtime-config.js` | 像素比、粒子数量、星点比例、后期开关、更新频率和手机主角尺寸可统一调整 |
| 人物低负载采样优先保留脸与头发 | 数量减少时仍保留额头、鼻子、下巴和头发轮廓；没有重新移动相机或随机改变源形状 |
| 人物画布按显示尺寸绘制 | 避免手机仍使用固定 1254px 画布；像素比上限实际作用于缓冲区 |
| Bloom 按需创建并在关闭时销毁 | 关闭后期时不占用额外的 Bloom WebGL 上下文、纹理和渲染目标；主动销毁不会被误判为图形故障 |
| 统一注册 / 挂载 / 暂停 / 释放流程 | 重复初始化不叠加画布、监听或动画；快速切换可以取消尚未启动的工厂和正在加载的资源 |
| 隐藏时暂停、恢复时重置帧时间 | 避免后台持续更新视觉，也避免恢复后用很大的帧间隔跳过过渡；deltaTime 上限 0.05 秒 |
| 图形与音频输出分开管理 | 视觉释放时保留单个音频元素及原有 AudioContext、Source、Gain、Analyser；不会叠出第二条音轨 |

## 集中参数

| 参数 | 标准 | 低负载 | 静态 |
| --- | ---: | ---: | ---: |
| 像素比上限 | 1.5 | 1 | 无 WebGL 主角 |
| 签名粒子 | 14,000 | 4,500 | 0 |
| 人物粒子 | 36,000 | 9,000 | 0 |
| 人物软亮点 | 33 | 10 | 0 |
| 背景星点数量预算 | 100% | 45% | 静态 SVG |
| 后期 | 可选，默认关闭 | 关闭 | 关闭 |
| 人物更新上限 | 18 Hz | 10 Hz | 0 |
| 音乐视觉计算上限 | 60 Hz | 24 Hz | 0 |
| 音频数据读取上限 | 30 Hz | 15 Hz | 10 Hz（仅播放状态需要时） |

音频数据读取与视觉联动分开。静态模式不使星点闪动；手动完整释放视觉运行器时也停止波形采样帧，声音仍可播放。这里是更新频率上限，不是手机帧率测量结果。

实际缓冲区测量：1600×1000、DPR 2 的桌面模拟中，标准签名为 1333×1032、人物为 1032×1032；低负载对应 889×688、688×688。390×844、DPR 3 的手机模拟中，低负载人物只有 242×242，签名为 366×242。

## 浏览器模拟验证

环境：Windows 上的 Edge / Chromium，Playwright 无头运行，使用 SwiftShader。模拟视口、DPR、触控与减少动效偏好。音频在浏览器中实际进入播放状态并采样，测试启动参数将声音静音，不代表试听音质验证。

| 检查 | 结果与方法 |
| --- | --- |
| 320×568 / DPR 2 | 无横向溢出；正文、链接与项目键盘操作可用。短屏幕的签名在正文之后，需要向下滚动查看 |
| 390×844 / DPR 3 | 签名位于正文下方；人物位于关于文字下方；设置切换与 Esc 关闭、焦点返回菜单按钮通过 |
| 430×932 / DPR 3 | 构图、实际低负载数量、项目切换与关闭通过 |
| 横屏 844×390 / DPR 2、触控 | 自动低负载、菜单与正文排版通过；纵向空间较短时主角可在下一屏继续出现 |
| 两个真实项目连续选择 / 关闭 | Enter、Esc、焦点恢复、详情与星图同步；静态模式使用 SVG，链接保留真实 href |
| 同一音乐视觉开关回归 | 关闭时基础亮度为 1，开启后随实际音乐增强；没有替换音频或音频节点 |
| 重复初始化 | 连续调用 25 次 `init()`，挂载次数不增加；重复导入 4 个模块和加载 3 个核心脚本，没有重复画布、菜单或控制条 |
| 快速切换 | 6 次依次切换，再做 20 次同一任务内快速切换并最终回到低负载；取消的初始化不留下画布 |
| 隐藏 / 恢复信号 | **合成测试**：覆盖 `document.hidden` / `visibilityState` 并派发 `visibilitychange`。隐藏后受管帧请求与计时器均为 0，音频采样和人物绘制计数不再增长；恢复后继续读取原链路 |
| 浏览器冻结 / 恢复 | **浏览器生命周期模拟**：通过 DevTools `Page.setWebLifecycleState` 冻结 500ms，再恢复；没有第二条音轨，计算的 deltaTime 仍不超过 0.05 秒。这与手机真实后台行为不同 |
| 减少动效 | 浏览器偏好模拟后进入静态；移除主角和 Bloom 画布，视觉联动关闭；音乐仍可反复主动播放 / 暂停 |
| WebGL 不可用 | 拦截 WebGL 上下文创建并返回 null，自动静态回退；静态素材成功加载，正文选择、电话链接和项目操作通过 |
| 上下文丢失与重试 | 在实际创建的模拟 WebGL 上下文调用 `WEBGL_lose_context`；进入静态，重试后恢复单组画布 |
| 完整释放与重新初始化 | 所有受管 scope、帧请求、计时器、观察器和 DOM 画布归零；ScrollTrigger 数量为 0。重新初始化只创建一组视觉资源 |
| GPU 资源 API 检查 | 签名、人物、项目 renderer 的 geometry / texture 计数清零，program 计数为 0，画布移除，并主动丢弃上下文。材质、后期目标和纹理调用了 dispose；不把这些计数称为操作系统显存字节测量 |
| 音频资源复用 | 一次 AudioContext、一次 MediaElementSource、一次 Gain、一次 Analyser、三条连接；质量切换和视觉释放 / 恢复后，实际节点和采样数组身份不变 |
| 中段加载 / 刷新 / 向上返回 | 直接打开 `#about`、刷新后定位关于，再通过导航回到首屏，通过 |
| 未捕获页面错误 | 0；预期的 WebGL 创建失败属于故障注入，并已被回退流程处理 |

完整数据见 [verification.json](verification.json)，复现脚本见 [verify-mobile-load.py](verify-mobile-load.py)。浏览器截图尺寸以 CSS 像素保存，DPR 不等于截图文件尺寸。

对照页的图片尺寸切换、桌面 / 手机排版，以及原有音乐对照页的实际播放 / 暂停另行通过检查，见 [review-verification.json](review-verification.json)。早期灯光对照页仍能切换原配色、Bloom 关和 Bloom 开，见 [legacy-verification.json](legacy-verification.json)。
